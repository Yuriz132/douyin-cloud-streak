## 1. 新手先看：6 个编号脚本都是干嘛的？

项目文件夹里有 **6 个带编号的脚本**，每个都是一个独立功能按钮：

### 1.1 六个编号脚本作用速查表

| 脚本 | 名字 | 什么时候需要点它 | 点了会发生什么 |
|---|---|---|---|
| **`1.本地提取通行证.bat`** | 电脑上扫码登录 + 自动同步联系人 + 启动本地后台 | 推荐先在本地电脑用手机扫码登录（家庭宽带 IP 风控最宽松）。会弹出浏览器窗口扫码登录，登录成功后**自动同步联系人到本地台账**，并**自动启动本地后台**、打开 `http://127.0.0.1:8000` | 自动装好依赖 → 弹出 Chromium 浏览器打开抖音登录页 → 你扫码 → 保存 `data\state.json` → 自动同步联系人 → 启动本地后台 |
| **`2.桌面端立即运行.bat`** | 电脑上立刻跑一次任务 | 只用「家里电脑运行」模式时才会用到。可选正式发送 / 模拟演练 / 仅同步好友列表三种模式 | 直接在电脑上执行一次续火花流程（不发消息的演练模式也有） |

| **`4.同步登录态到服务器.bat`** | 把电脑上的凭证 + 联系人台账秒传到服务器 | 只有走「路线 B」且凭证过期时才需要。输入服务器 IP 和密码，1 秒传完 | 把本机 `data\state.json` 和 `data\ledger.json` 上传到服务器对应账号目录，云端立即生效 |

| **`6.Docker部署.bat`** | Docker 容器化部署到云服务器（依赖已封装进镜像，升级环境更干净） | 服务器已装/想用 Docker 时选这个。自动装 Docker → 国内镜像加速 → 构建启动 | 自动打包上传 → 远程安装 Docker → `docker compose build`（国内源加速）→ 启动容器 → 输出访问网址 |

## 2. 第一步：准备一台国内云服务器（重要）

### 2.1 为什么强烈建议买「国内、最好同城」的服务器？
抖音判断「是不是你本人在登录」，核心依据是 **登录 IP 的城市特征**：
1. **IP 归属地一致性**：如果你常住**上海**，服务器也买在**上海**节点，登录 IP 和日常城市完全吻合，被风控拦截的概率极低；
2. **避免境外节点**：境外节点（香港、日本、美国等）极易触发抖音「境外/异地登录」风控，导致消息发不出去或频繁弹验证码；
3. **低延迟稳定**：同城网络延迟仅几毫秒，页面秒加载，任务执行最稳定。

> 💡 **购买推荐**：阿里云「轻量应用服务器」或腾讯云「轻量服务器」，选择 **Ubuntu 22.04 / 24.04 64位** 系统，设置好 **root 登录密码**。
>
> 🎓 学生党可先用第 0 节福利里的**免费/学生优惠教程**零成本体验，确定要长期用了再买正式服务器。

### 2.2 关键设置：放行防火墙端口（防网页打不开）
服务器创建好后，打开云控制台的 **「防火墙 / 安全组」** 设置，确保添加了以下两条入方向规则：
* **`22 端口 (TCP)`**：用于本地连接服务器进行一键部署；
* **`8000 端口 (TCP)`**：用于打开网页控制台管理好友。

> ⚠️ 很多新手部署完打不开网页，**90% 都是忘了这一步**。先放行端口，再继续往下。

### 2.3 需要一台能跑 Python 的电脑（仅「一键部署」这一步用）
* 「一键部署」脚本需要在**任意一台装了 Python 的电脑**上双击运行（借朋友的电脑装一次也行，部署完就还回去 😄）；
* **不会装 Python？** 见下：
  1. 打开 https://www.python.org/downloads/ 下载 Windows 版安装包；
  2. 安装时**务必勾选最底部的 `Add Python to PATH`**，否则脚本会提示找不到 Python；
  3. 一路 Next 装完即可，无需配置任何环境变量。

## 3. 第二步（路线 A）：双击 `5`，一键部署到云服务器

无需掌握任何 Linux 命令，无需手动敲 SSH，双击即可全自动完成整站配置！

1. 把本项目源码下载解压到**任意一台装有 Python 的电脑**上（借朋友的电脑装一次也行，部署完就还回去 😄）；
2. 打开文件夹，**双击运行**：
   👉 **`5.服务器部署.bat`**（systemd 方式，推荐）或 **`6.Docker部署.bat`**（Docker 方式）
3. 按屏幕提示依次输入（记不清的直接回车用默认值）：

   | 提示 | 输入什么 |
   |---|---|
   | 👉 云服务器公网 IP 地址 | 你的服务器 IP，例如 `123.45.67.89`（云控制台首页复制） |
   | 👉 SSH 用户名 | 直接回车（默认 `root`） |
   | 👉 SSH 端口号 | 直接回车（默认 `22`） |
   | 👉 部署路径 | 直接回车（默认 `/opt/douyin-cloud-streak`） |
   | 🔑 服务器密码 | 你的 root 密码（支持右键粘贴，输入时明文可见） |

4. 脚本会在 **1~2 分钟内** 全自动完成：
   * 生产代码极速打包与秒级上传；
   * 自动配置 Python 虚拟环境与 Playwright 浏览器内核（**国内源加速**）；
   * 自动注册 Linux Systemd 开机自启守护进程并启动服务！
   * **若你本地已经跑过 `1.本地提取通行证.bat`**，登录态与联系人台账会**一并同步到服务器**，无需在服务器上再同步一次联系人。
5. 当屏幕输出下面的信息时，部署就全部搞定了：

   ```
   🎉🎉🎉 恭喜！云服务器已全部部署完成并成功启动！
   🌐 Web 管理后台地址: http://123.45.67.89:8000      ← 这就是你的专属网址
   🔑 访问安全令牌 (Token): spark_secret_token_change_me
   ```

> ⚠️ **请务必记下部署输出的网址和 Token**，后面登录和管理都要用到。Token 忘了也不怕，SSH 进服务器执行 `grep AUTH_TOKEN /opt/douyin-cloud-streak/.env` 就能找回。

## 4. 第三步（路线 A）：手机打开网址，直接扫码登录 🆕

**从这一步开始，再也不需要电脑了，一部手机搞定！**

1. 用手机浏览器（或电脑浏览器）打开刚才输出的网址：
   👉 **`http://你的服务器IP:8000`**
2. 若提示输入访问令牌 Token：点击右上角「**令牌**」，填入部署完成时显示的 Token（默认 `spark_secret_token_change_me`）后保存；
3. 点击左侧菜单进入 **「凭证」** 页面；
4. 点击蓝色的 **「📱 手机扫码登录」** 按钮，会先弹出一份《扫码须知》，确认自己已备好手机后点击「**已备好手机，开始扫码**」；
5. 页面会在 **20~40 秒** 内生成二维码 → 用**另一台手机的抖音 App** 扫一扫（或者截图后用抖音内置扫一扫识别相册图片）；

   > 💡 也可以直接用当前这台手机：长按二维码保存图片，再到抖音 App「我-右上角菜单-扫一扫-相册」选取该图片。
6. 扫码确认后，页面提示「登录成功」即大功告成！

### ❓ 关于「人脸验证」的疑问：登录一定要刷脸吗？

**不是的，平时登录就是普通的扫二维码，90% 以上的情况直接扫码就成功了。**

你遇到的「人脸验证」，其实是抖音的**二次安全验证（风控）**机制，跟本项目的登录方式无关：

| 场景 | 发生了什么 | 你要做什么 |
|---|---|---|
| ✅ 绝大多数情况 | 扫码确认后直接登录成功 | 无 |
| ⚠️ 偶尔触发风控 | 抖音要求「二次验证」，页面出现**新的二维码**，常见形式是「手机刷脸验证」 | 按网页提示，用抖音 App 扫这个新二维码，在手机上完成刷脸/确认后回到网页，系统会自动检测通过 |

几点说明：
1. **是否触发验证、给哪种验证方式（刷脸 / 短信等），完全由抖音的风控系统临时决定**，任何工具都无法指定；本项目已针对「刷脸验证」分支实现了自动化引导，实测可通过；
2. 触发概率与服务器 IP 归属地有关——这也是教程反复强调**买同城国内节点**的原因；
3. 如果实在过不了验证，可改走「路线 B」：在家里常用网络的电脑上双击 `1.本地提取通行证.bat` 登录（家庭宽带 IP 风控最宽松），登录后会自动同步联系人，再用 `5.服务器部署.bat` 一并同步到服务器。

## 5. 第四步：同步联系人，勾选好友，开启自动续火花

### 5.1 同步并勾选火花好友（3 步搞定）
1. 在左侧菜单点击进入 **「好友」** 页面；
2. 点击上方 **「🚀 同步联系人」** 按钮，系统会在后台自动拉取你的抖音好友列表与当前火花天数（约 10~30 秒，人多会稍慢，请勿关闭页面），列表默认**按火花天数从高到低排列**；
3. 点击 **「✨ 一键勾选火花好友」**（系统自动勾选所有带火花的好友），也可手动增删；
4. 最后点击 **「💾 保存勾选配置」** 生效！

> 💡 走「路线 B」（先本地跑过 `1`）的用户，联系人已在本地同步好，部署时随登录态一并传到了服务器，**这一步通常可以直接看到好友，无需再点同步**。

### 5.2 设置发送时间与内容（可选）
* 点击左侧 **「定时」**：
  * **定时时间**：默认每天 `21:00`，可随意修改；
  * **随机浮动时间**：如 `30` 分钟（系统会在 20:30~21:30 之间随机挑选时间发送，模拟真人行为）；
  * **发送内容**：默认每行一条（支持 `🔥`、`早安`、`今天也要开心哦` 等自定义文案）；
  * 修改后点击 **「保存设置」** 即可实时生效，无需重启！

### 5.3 如何确认每天真的发了？
* 网页左侧 **「日志」** 页可实时查看每一次发送记录（几点发、发给谁、成功/失败原因）；
* 发送时间到点后，打开抖音 App 看对应好友的会话即可验证收到消息；
* 也可在「好友」页看到每个好友的「最后发送时间」。

## 8. Docker 部署（进阶：一条命令跑起来）

> 适合：会用命令行、想要**环境隔离 + 升级回滚方便 + 开机自启**的用户。完全零 Docker 经验也只需复制粘贴下面几条命令，全程约 5~10 分钟（视网速）。
>
> 💡 **不想手动敲命令**：直接用 **`6.Docker部署.bat`** 能全自动完成第 8 节的所有操作（打包上传 → 自动装 Docker → 国内镜像加速 → 构建启动）。以下为手动步骤，两条路二选一。

### 8.1 为什么选 Docker？

| 对比项 | 脚本一键部署（第 3 节） | Docker 部署（本节） |
|---|---|---|
| 上手难度 | 最简单，双击即可 | 需要会基本 SSH 命令（本节全给出，可照抄） |
| 环境依赖 | 直接装在系统里 | 全部封装在容器内，与系统零耦合 |
| 升级版本 | 重新跑一遍脚本 | `git pull` + 一条重启命令 |
| 换服务器迁移 | 重新部署 | 拷走 `data/` 目录即可 |
| 出问题排查 | 看系统日志 | `docker logs` 一目了然 |

### 8.2 第一步：安装 Docker（已装可跳过）

SSH 登录服务器后执行（国内服务器用下面的官方加速脚本，一路回车即可）：

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
```

装完验证并设置开机自启：

```bash
# 验证版本
docker --version

# 设置开机自启
systemctl enable --now docker
```

> 💡 国内拉取 Docker 官方镜像慢或报超时？编辑 `/etc/docker/daemon.json`（没有就新建）写入以下内容后执行 `systemctl restart docker`：
>
> ```json
> { "registry-mirrors": ["https://docker.m.daocloud.io", "https://docker.mirrors.ustc.edu.cn", "https://mirror.baidubce.com"] }
> ```
>
> 若仍慢，请使用阿里云容器镜像服务「镜像加速器」页面的专属加速地址（需登录阿里云账号，地址形如 `https://<你的id>.mirror.aliyuncs.com`）。

### 8.3 第二步：获取项目代码

```bash
# 没有 git 先装一个
apt-get install -y git

# 拉取项目
git clone https://github.com/Yuriz132/douyin-cloud-streak.git
cd douyin-cloud-streak
```

### 8.4 第三步：修改访问口令（重要！）

```bash
# 编辑 compose 配置
nano docker-compose.yml
```

找到 `AUTH_TOKEN=spark_secret_token_change_me` 这一行，把 `spark_secret_token_change_me` 改成**你自己的一串字母数字**（如 `AUTH_TOKEN=my-secret-2026abc`）。
改完按 `Ctrl+O` 回车保存，`Ctrl+X` 退出。

> ⚠️ 不改口令 = 任何知道你 IP 的人都能打开你的控制台。这是唯一必改项！

### 8.5 第四步：构建并启动

```bash

```

看到 `Container douyin-cloud-streak  Started` 即成功。浏览器访问：

首次打开会要求输入访问口令——填上面 8.4 设置的那串即可。

### 8.7 版本升级（三行命令）

## 10. 常见问题排错 (FAQ)

### Q1: 部署完成后，浏览器打不开 `http://服务器IP:8000`？
* **检查 1**：请在云厂商控制台「**防火墙 / 安全组**」中放行 **8000 端口 (TCP)** 入方向规则；
* **检查 2**：确认访问地址格式为 `http://` 开头（本系统暂不支持 https 直连）。

### Q2: 扫码页面的二维码一直出不来 / 显示等待超时？
* 二维码生成约需 **20~40 秒**（首次冷启动稍慢），请耐心等待并留意弹窗提示；
* 若超过 1 分钟仍无二维码，点击「取消」后重新发起一次；
* 多次失败通常是服务器网络无法访问抖音，可在「日志」页查看具体报错。

### Q3: 扫码后一直转圈不出结果？
* 大概率触发了二次安全验证：请仔细观察页面上的提示与新出现的二维码，按第 4 步的「人脸验证」说明处理；
* 仍未解决可点「取消」释放名额，等 1 分钟后重试。

### Q4: 点击「同步联系人」或「立即续火花」提示执行中，怎么停止？
* 在网页顶部点击红色的 **「强制停止 / 重置」** 按钮，系统会秒级释放后台锁并恢复空闲状态。

### Q5: 换了一台新电脑使用，程序怎么找到项目文件？
* 本项目全部采用 **动态相对寻路（`%~dp0` 与 `Path(__file__)`）**，无论放在桌面、D 盘还是移动硬盘，直接双击运行即可，无需配置路径。

### Q6: 如何查看真实的运行日志？
* 网页端点击左侧 **「日志」** 页实时查看；
* 服务器端可执行：`journalctl -u douyin-cloud-streak -f`（systemd 版）或 `docker compose logs -f`（Docker 版）。

### Q7: 在自己电脑手动执行 `pip install` 报错哈希校验失败？
* **报错特征**：`THESE PACKAGES DO NOT MATCH THE HASHES FROM THE REQUIREMENTS FILE.`
* **原因**：网络代理或运营商劫持导致从官方 pypi 下载的包内容被篡改，无法通过本项目的精确版本安全校验。
* **解决方案**：请改用国内清华镜像源进行安装，即可绕过网络干扰：

```bash
# 使用清华镜像源安装
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q8: 同步联系人后，网页端一个联系人都没有？
* **最常见原因：打开了旧的后台实例**。如果你电脑上之前运行过后台（或上次解压目录的后台没关），新目录的脚本检测到 `8000` 端口被占用时，会自动换用下一个端口（如 `8001`）启动，**请留意黑框打印的端口号，用那个端口访问**；
* 确认台账确实写入了数据：打开 `data\ledger.json` 看是否有联系人记录；
* 若确实为空，多数是登录态未生效或列表还在加载，重跑一次 `1.本地提取通行证.bat` 即可。

### Q9: 同步联系人时提示「同步联系人为空」或「过半联系人火花为空」？
* 抖音网页聊天页冷启动时，左侧列表会先渲染**骨架屏**（一串占位的 "word" 文本），脚本会条件等待真实列表渲染（最多 40 秒），通常等一等就能成功；
* 若仍失败，检查 `data\debug_dom.png` 诊断截图（若生成了）判断是「未登录」还是「列表未渲染」；
* 网页聊天端对部分好友不展示火花标记属正常现象，可在后台**手动勾选**需要续火花的好友，发送时会自动从会话页校准火花天数。

### Q10: 发送失败 / 部分好友发不出去？
* 查看「日志」页的失败原因：
  * **「触发限流 / 需要验证码」**：短时间内发送过多，系统已自动熔断，等几小时后再试，建议减少勾选人数；
  * **「登录失效」**：见第 9 节重新扫码；
  * **「对方未关注 / 陌生人会话限制」**：抖音限制陌生人只能发 1 条，这类好友无法自动续火花，属正常。

### Q11: 每天发送的最佳实践是什么？
* 建议勾选 **20 人以内**，时间选在**白天活跃时段**（如 09:00、12:00、21:00）；
* 开启 **随机浮动时间**（如 30 分钟），让发送时刻更接近真人；
* 先用**小号**试跑一周确认稳定，再切主力号。

## 11. 多账号同时续火花 (Multi-Account)

支持**一个服务同时管理多个抖音账号**，每个账号独立登录、独立勾选好友、独立定时：

### 11.1 核心特性
- **数据完全隔离**：每个账号拥有独立的 `data/accounts/{id}/` 目录，互不串数据，删除账号自动归档；
- **独立定时任务**：每个账号可设置各自的发送时间，调度器按账号分别注册 job；
- **全局并发保护**：同时最多开 **5 个**浏览器会话（可在 `core/accounts.py` 的 `MAX_CONCURRENT_BROWSERS` 修改），超出自动排队，防风控；
- **兼容旧版**：原 `data/` 根目录数据自动作为 **默认账号（default）** 原地生效，零迁移升级。

### 11.2 使用步骤
1. 网页后台左侧点 **「账号」** → **「+ 新建账号」**；
2. 顶部下拉框切换到新账号 → 「凭证」页扫码登录或上传 `state.json`；
3. 「好友」页同步并勾选 →「定时」页设置发送时间；
4. 「账号」页可查看各账号状态，支持启停 / 改名 / 删除。

## 12. 项目原理：它是怎么做到每天自动发的？

本项目由 4 个核心环节组成，全部本地/私有化运行，**不经过任何第三方中转**：

1. **登录态（state.json）**：保存你在抖音网页端的登录凭证（Cookie）。你可以：
   * 在**服务器网页端**直接扫码生成；
   * 或在**家里电脑**扫码生成后上传（路线 B）。
2. **联系人台账（ledger.json）**：本地持久化的好友库，记录每个好友的显示名、火花天数、头像、是否勾选、最后发送时间等。每次「同步联系人」都会增量更新它。
3. **定时调度**：服务器上的守护进程（systemd 服务或 Docker 容器）按你设定的时间唤醒，自动打开浏览器、给勾选的好友发送设定内容。
4. **反风控设计**：单工作线程串行执行、全局并发限制（最多 5 个浏览器会话）、随机浮动发送时间、火花天数非降级保护等，尽量模拟真人行为。

**数据都在哪？** 全部存在项目的 `data/` 目录（含登录凭证、联系人台账、日志、头像缓存）。**代码里不会把任何数据上传到第三方**；凭证与台账仅在你自己的电脑与你的服务器之间通过 SSH 传输。
