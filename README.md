## 2. 第一步：准备一台国内云服务器（重要）

### 2.1 为什么强烈建议买「国内、最好同城」的服务器？
抖音判断「是不是你本人在登录」，核心依据是 **登录 IP 的城市特征**：
1. **IP 归属地一致性**：如果你常住**上海**，服务器也买在**上海**节点，登录 IP 和日常城市完全吻合，被风控拦截的概率极低；
2. **避免境外节点**：境外节点（香港、日本、美国等）极易触发抖音「境外/异地登录」风控，导致消息发不出去或频繁弹验证码；
3. **低延迟稳定**：同城网络延迟仅几毫秒，页面秒加载，任务执行最稳定。

> 💡 **购买推荐**：阿里云「轻量应用服务器」或腾讯云「轻量服务器」，选择 **Ubuntu 22.04 / 24.04 64位** 系统，设置好 **root 登录密码**。

### 2.2 关键设置：放行防火墙端口（防网页打不开）
服务器创建好后，打开云控制台的 **「防火墙 / 安全组」** 设置，确保添加了以下两条入方向规则：
* **`22 端口 (TCP)`**：用于本地连接服务器进行一键部署；
* **`8000 端口 (TCP)`**：用于打开网页控制台管理好友。

## 3. 第二步：在本地电脑提取抖音登录凭证

> 🛡️ **安全原则**：登录凭证（`state.json`）在自己的电脑上安全生成，服务器只负责执行，绝不在服务器上输入账号密码。

1. 在本地电脑解压并打开 `douyin-cloud-streak` 文件夹；
2. **双击运行**：
   👉 **`1.本地提取通行证.bat`**
3. 脚本会自动唤起一个 Chromium 浏览器窗口并打开抖音登录页；
4. 用手机抖音 App **扫码登录**（或验证码登录）；
5. 登录成功进入抖音首页后，回到黑色脚本黑框按下 **回车键**；
6. 提示 `[✓] 登录凭证提取成功！已安全保存为 data\state.json`，即可关闭窗口。

## 4. 第三步：一键极速部署到云服务器（纯全自动）

无需掌握任何 Linux 命令，无需手动敲 SSH，双击即可全自动完成整站配置！

1. 打开 `douyin-cloud-streak` 文件夹；
2. **双击运行**：
   👉 **`5.一键部署整站到服务器.bat`**
3. 按屏幕提示依次输入：
   * **云服务器公网 IP 地址**（例如 `123.45.67.89`，在云控制台复制）；
   * **SSH 用户名**（直接按回车，默认 `root`）；
   * **SSH 端口号**（直接按回车，默认 `22`）；
   * **服务器密码**（输入或右键粘贴你的 root 密码，按回车）；
4. 脚本会在 **1~2 分钟内** 全自动完成：
   * 生产代码极速打包与秒级上传；
   * 自动配置 Python 虚拟环境与 Playwright 依赖；
   * 自动注册 Linux Systemd 开机自启守护进程并启动服务！
5. 当屏幕输出 `🎉🎉🎉 恭喜！云服务器已全部部署完成并成功启动！` 时，部署即全部搞定！

## 5. 第四步：打开网页控制台，勾选好友并开启自动续火花

部署完成后，即可在手机或电脑浏览器中随时管理：

### 5.1 打开网页管理后台
* 浏览器访问：`http://你的服务器IP:8000`
* （首次使用若提示输入访问令牌 Token，点击右上角「**令牌**」，输入终端提示的 Token 或默认 `spark_secret_token_change_me` 保存即可）。

### 5.2 勾选续火花好友（3 步搞定）
1. 在左侧菜单点击进入 **「好友与消息」** 页面；
2. 点击上方 **「🚀 同步联系人」** 按钮，系统会在后台自动拉取你的抖音好友列表与当前火花天数（约 10~15 秒）；
3. 同步完成后，点击 **「✨ 一键勾选火花好友」**（系统会自动帮你勾选所有带有火花的好友）；
4. 最后点击 **「💾 保存勾选配置」** 生效！

### 5.3 设置发送时间与内容（可选）
* 点击左侧 **「定时与风控」**：
  * **定时时间**：默认每天 `21:00`，可随意修改；
  * **随机浮动时间**：如 `30` 分钟（系统会在 20:30~21:30 之间随机挑选时间发送，模拟真人行为）；
  * **发送内容**：默认每行一条（支持 `🔥`、`早安`、`今天也要开心哦` 等自定义文案）；
  * 修改后点击 **「保存设置」** 即可实时生效，无需重启！

## 7. 第六步：日常维护（凭证过期了怎么办？）

由于抖音安全机制，网页登录态一般维持 **几天到几周** 后会自然过期。

当网页控制台顶部提示「**未检测到登录态**」或「**登录凭证已失效**」时，只需 **2 步极速复活**：
1. 本地电脑双击运行 **`1.本地提取通行证.bat`** 重新扫码登录一次；
2. 双击运行 **`4.同步登录态到服务器.bat`**，输入服务器 IP 密码，1 秒钟即可将新凭证同步到云端！
3. 云服务器会自动无缝采用新凭证继续每日任务，无需重新部署。

## 8. 常见问题排错 (FAQ)

### Q1: 部署完成后，浏览器打不开 `http://服务器IP:8000`？
* **检查 1**：请检查云服务器厂商控制台（阿里云/腾讯云），在「**防火墙 / 安全组**」中是否添加了放行 **8000 端口 (TCP)** 的入方向规则；
* **检查 2**：确认访问地址格式为 `http://` 而不是 `https://`。

### Q2: 点击「同步联系人」或者「立即续火花」提示执行中，怎么停止？
* 如果任务卡住，直接在网页顶部导航栏点击红色的 **「强制停止 / 重置」** 按钮，系统会秒级释放后台锁并恢复空闲状态。

### Q3: 换了一台新电脑使用，程序怎么找到项目文件？
* 本项目全部采用 **动态相对寻路（`%~dp0` 与 `Path(__file__)`）**，无论你把文件夹放在桌面上、D盘、移动硬盘还是换电脑使用，直接双击运行即可，完全不需要手动配置路径。

### Q4: 如何查看真实的运行日志？
* 在网页端点击左侧 **「运行日志」**，即可实时查看深色控制台终端日志；
* 也可以在服务器端执行命令查看：`journalctl -u douyin-cloud-streak -f`。
