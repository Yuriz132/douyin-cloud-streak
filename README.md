## 2. 第一步：准备一台国内云服务器（重要）

### 2.1 为什么强烈建议买「国内、最好同城」的服务器？
抖音判断「是不是你本人在登录」，核心依据是 **登录 IP 的城市特征**：
1. **IP 归属地一致性**：如果你常住**上海**，服务器也买在**上海**节点，登录 IP 和日常城市完全吻合，被风控拦截的概率极低；
2. **避免境外节点**：境外节点（香港、日本、美国等）极易触发抖音「境外/异地登录」风控，导致消息发不出去或频繁弹验证码；
3. **低延迟稳定**：同城网络延迟仅几毫秒，页面秒加载，任务执行最稳定。

> 💡 **购买推荐**：阿里云「轻量应用服务器」或腾讯云「轻量服务器」，选择 **Ubuntu 22.04 / 24.04 64位** 系统，设置好 **root 登录密码**。

### 2.2 关键设置：放行防火墙端口（防网页打不开）
服务器创建好后，打开云控制台的 **「防火墙 / 安全组」** 设置，确保添加了以下两条入方向规则：
* **`22 端口 (TCP)`**：用于本地连接服务器进行一键部署；
* **`8000 端口 (TCP)`**：用于打开网页控制台管理好友。

## 4. 第三步（路线 A）：手机打开网址，直接扫码登录 🆕

**从这一步开始，再也不需要电脑了，一部手机搞定！**

1. 用手机浏览器（或电脑浏览器）打开刚才输出的网址：
   👉 **`http://你的服务器IP:8000`**
2. 若提示输入访问令牌 Token：点击右上角「**令牌**」，填入部署完成时显示的 Token（默认 `spark_secret_token_change_me`）后保存；
3. 点击左侧菜单进入 **「凭证」** 页面；
4. 点击蓝色的 **「📱 手机扫码登录」** 按钮，会先弹出一份《扫码须知》，确认自己已备好手机后点击「**已备好手机，开始扫码**」；
5. 页面会在 **20~40 秒** 内生成二维码 → 用**另一台手机的抖音 App** 扫一扫（或者截图后用抖音内置扫一扫识别相册图片）；

   > 💡 也可以直接用当前这台手机：长按二维码保存图片，再到抖音 App「我-右上角菜单-扫一扫-相册」选取该图片。
6. 扫码确认后，页面提示「登录成功」即大功告成！

### ❓ 关于「人脸验证」的疑问：登录一定要刷脸吗？

**不是的，平时登录就是普通的扫二维码，90% 以上的情况直接扫码就成功了。**

你遇到的「人脸验证」，其实是抖音的**二次安全验证（风控）**机制，跟本项目的登录方式无关：

| 场景 | 发生了什么 | 你要做什么 |
|---|---|---|
| ✅ 绝大多数情况 | 扫码确认后直接登录成功 | 无 |
| ⚠️ 偶尔触发风控 | 抖音要求「二次验证」，页面出现**新的二维码**，常见形式是「手机刷脸验证」 | 按网页提示，用抖音 App 扫这个新二维码，在手机上完成刷脸/确认后回到网页，系统会自动检测通过 |

几点说明：
1. **是否触发验证、给哪种验证方式（刷脸 / 短信等），完全由抖音的风控系统临时决定**，任何工具都无法指定；本项目已按商业版逻辑实现了「刷脸验证」分支的自动化引导，实测可通过；
2. 触发概率与服务器 IP 归属地有关——这也是教程反复强调**买同城国内节点**的原因；
3. 如果实在过不了验证，可改走「路线 B」：在家里常用网络的电脑上双击 `1.本地提取通行证.bat` 登录（家庭宽带 IP 风控最宽松），再用 `4` 上传到服务器。

## 8. 日常维护：凭证过期了怎么办？

由于抖音安全机制，网页登录态一般维持 **几天到几周** 后会自然过期。当控制台顶部提示「未检测到登录凭证」或发送失败提示登录失效时：

| 你用的路线 | 复活方法 |
|---|---|
| 🌟 路线 A（网页扫码） | 打开控制台 → 「凭证」页 → 再点一次「📱 手机扫码登录」重新扫即可，**30 秒搞定** |
| 路线 B（电脑提取） | 电脑双击 `1.本地提取通行证.bat` 重新扫码 → 双击 `4.同步登录态到服务器.bat` 上传 |

凭证更新后云端自动无缝采用，无需重新部署。

## 9. 常见问题排错 (FAQ)

### Q1: 部署完成后，浏览器打不开 `http://服务器IP:8000`？
* **检查 1**：请在云厂商控制台「**防火墙 / 安全组**」中放行 **8000 端口 (TCP)** 入方向规则；
* **检查 2**：确认访问地址格式为 `http://` 开头（本系统暂不支持 https 直连）。

### Q2: 扫码页面的二维码一直出不来 / 显示等待超时？
* 二维码生成约需 **20~40 秒**（首次冷启动稍慢），请耐心等待并留意弹窗提示；
* 若超过 1 分钟仍无二维码，点击「取消」后重新发起一次；
* 多次失败通常是服务器网络无法访问抖音，可在「日志」页查看具体报错。

### Q3: 扫码后一直转圈不出结果？
* 大概率触发了二次安全验证：请仔细观察页面上的提示与新出现的二维码，按第 4 步的「人脸验证」说明处理；
* 仍未解决可点「取消」释放名额，等 1 分钟后重试。

### Q4: 点击「同步联系人」或「立即续火花」提示执行中，怎么停止？
* 在网页顶部点击红色的 **「强制停止 / 重置」** 按钮，系统会秒级释放后台锁并恢复空闲状态。

### Q5: 换了一台新电脑使用，程序怎么找到项目文件？
* 本项目全部采用 **动态相对寻路（`%~dp0` 与 `Path(__file__)`）**，无论放在桌面、D 盘还是移动硬盘，直接双击运行即可，无需配置路径。

### Q6: 如何查看真实的运行日志？
* 网页端点击左侧 **「日志」** 页实时查看；
* 服务器端可执行：`journalctl -u douyin-cloud-streak -f`。

## 10. 多账号同时续火花 (Multi-Account)

支持**一个服务同时管理多个抖音账号**，每个账号独立登录、独立勾选好友、独立定时：

### 10.1 核心特性
- **数据完全隔离**：每个账号拥有独立的 `data/accounts/{id}/` 目录，互不串数据，删除账号自动归档；
- **独立定时任务**：每个账号可设置各自的发送时间，调度器按账号分别注册 job；
- **全局并发保护**：同时最多开 **5 个**浏览器会话（可在 `core/accounts.py` 的 `MAX_CONCURRENT_BROWSERS` 修改），超出自动排队，防风控；
- **兼容旧版**：原 `data/` 根目录数据自动作为 **默认账号（default）** 原地生效，零迁移升级。

### 10.2 使用步骤
1. 网页后台左侧点 **「账号」** → **「+ 新建账号」**；
2. 顶部下拉框切换到新账号 → 「凭证」页扫码登录或上传 `state.json`；
3. 「好友」页同步并勾选 →「定时」页设置发送时间；
4. 「账号」页可查看各账号状态，支持启停 / 改名 / 删除。
